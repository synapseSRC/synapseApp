# SynapseApp UX Maintenance Skill

This folder is an Agent Skill following the Agent Skills format.

- Required entrypoint: `SKILL.md`
- Detailed stage instructions: `references/`
- FAQ: `references/faq.md`

Install or copy the entire `synapseapp-ux-maintenance/` directory into the skills
location supported by your agent. Activate it for SynapseApp autonomous UX bug
research, implementation, GitHub issue/PR management, and daily integration.

The skill requires working repository/GitHub access and a task-management mechanism.
It must disclose unavailable capabilities rather than claim unsupported actions.
